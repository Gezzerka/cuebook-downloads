# Cuebook

Free offline theatre script reader and cue annotator for Windows and macOS.

[Download the latest release](https://github.com/Gezzerka/cuebook-downloads/releases/latest) · [Website](https://cuebook.co.uk) · [Optional donations on Ko-fi](https://ko-fi.com/cuebook)

Choose the Windows x64 installer, Apple Silicon Mac DMG (arm64), or Intel Mac DMG (x64). Downloads are free and do not require an account or mailing-list signup.

Cuebook 1.0.3 adds an About window: click the Cuebook logo to see the version, copyright and website and donation links.

Windows builds are unsigned. Mac builds are ad-hoc signed and are not Apple-notarized. Operating-system security prompts may appear.

This repository contains public downloads and release notes. Software source is maintained separately.
