# Cuebook

Free theatre script reader and cue annotator. Use Cuebook in your browser, or download the offline app for Windows and macOS.

[Download the latest release](https://github.com/Gezzerka/cuebook-downloads/releases/latest) · [Website](https://cuebook.co.uk) · [Use Cuebook in your browser](https://app.cuebook.co.uk) · [Optional donations on Ko-fi](https://ko-fi.com/cuebook)

Choose the Windows x64 installer, Apple Silicon Mac DMG (arm64), or Intel Mac DMG (x64). Downloads are free and do not require an account or mailing-list signup.

Cuebook 1.0.7 brings sharper scripts and annotations, better handling of long scripts, tablet controls, quicker cue-note entry, printed page jumps and offsets, and a steady script layout when tool settings appear. Includes an updated desktop runtime. [Read the patch notes](https://cuebook.co.uk/release-notes.html).

Windows builds are unsigned. Mac builds are ad-hoc signed and are not Apple-notarized. Operating-system security prompts may appear.
